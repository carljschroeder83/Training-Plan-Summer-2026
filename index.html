Session strategy — the one-variable rule

Every session has exactly one target variable

Everything else is a constraint you hold constant so the target variable means something. Most sessions go wrong because the athlete optimises a constraint — usually pace — and destroys the target. Open the 🎯 intent panel on any session card for its aim, target variable, execution rule and named failure mode.

The 30-second pre-session ritual

Before you leave the house, answer three questions out loud: 1. What is this session's target variable — what am I trying to accumulate? 2. What is the one number I must not exceed? 3. What does failure look like today? Naming the failure mode in advance is what stops you doing it in the first 60 seconds, when the legs are fresh and you feel good.

Hybrid strength sessions — detail

Session A Power + lower body
  • Back squat — Ph1: 3×5 @70% (112kg) · Ph2: builds to 3×4 @80% (128kg) · Ph3: 3×3 @85% (136kg)
  • Romanian deadlift — 3×6 @80–100kg, progressing 5kg every 3 weeks. Cap at 3×5 in VO2 weeks — hamstring DOMS was showing up in run quality.
  • Push press — 3×5 @70–80kg. Keeps the overhead pattern alive.
  • Weighted pull-ups or lat pulldown — 3×6, add load or reps every 2 weeks
  • Bulgarian split squat — 2×8/leg, bodyweight → light DB → heavier DB across phases. Drop entirely in VO2 weeks (hip flexor soreness has been hitting the Saturday session).
  • Core — Hollow hold 3×40s, side plank 3×30s/side
Session B HIIT / metabolic circuit
  • Kettlebell swings — 4×15 → 4×20 → 5×15 across phases
  • Box jumps or broad jumps — 3×5. Plyometric power; direct running speed transfer.
  • DB goblet squat — 3×10, load increasing each phase
  • Push-up variation — 3×12 (standard → archer → weighted)
  • Renegade rows — 3×8/side.
  • Suitcase or farmer carry — 3×30m, load increasing each phase

Drop Session B entirely on deload and travel weeks. From Week 10 onward, Session B is retired — the Wednesday sweet spot ride takes its slot so Saturday VO2 running can go weekly.

Fatigue management

The soreness rule

If legs are sore on a quality run day, swap for easy. If sore on a strength day, drop to bodyweight only or skip.

Strength and running same day

Always run first. Quality run after heavy squats degrades badly; strength after easy run is fine.

VO2 stimulus comes from rep DURATION, not rep speed

Oxygen uptake takes roughly 90–120 seconds of hard running to reach VO2max — the kinetics are the rate limiter, not the effort. Run a rep faster and you don't arrive sooner, you just finish before the stimulus lands. At supramaximal pace, time at VO2max goes down. Keep reps ≥3 minutes, run them at the SLOW end of the band, and judge the session on minutes accumulated, not on rep splits.

Recoveries prime the next rep

Jog them — never stand or walk. The point isn't keeping HR high for its own sake: if VO2 only falls to ~70% between reps, rep 2 reaches VO2max in 40–50s instead of 120s, and rep 3 faster still. That priming compounds. Jog at 6:30–7:00/km, continuous. And prime before rep 1 — strides straight into the first rep, starting within 90 seconds. A long stand before the opener wastes your longest, most valuable rep.

HR is descriptive, not prescriptive (until max is measured)

No measured HRmax exists yet, so absolute BPM targets in this plan were guesses. Clean Myzone strap data from the Week 7 track ladder topped out at 164 across reps of escalating pace — if true max is ~178–182, that is ~90% and entirely correct for a VO2 rep. Until a max is measured (hill test in a deload week, or the Week 12 Parkrun finish), judge every session on pace band, cadence stability and rep completion. Log HR; don't chase it.

Deload weeks

Weeks 4, 8, 12 are planned deloads — volume drops ~30%. Don't skip them; this is where adaptation happens.
